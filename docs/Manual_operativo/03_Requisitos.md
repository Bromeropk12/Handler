# 3. REQUISITOS DE HARDWARE Y DE SOFTWARE

Para que el programa **Handler TrackSamples** funcione de manera fluida y sin interrupciones, el computador desde el cual lo utilices debe contar con unas características mínimas. 

### Requisitos Mínimos (Para uso diario)
*   **Computador:** Un PC de escritorio o laptop con procesador Intel Core i3 (o equivalente en marca AMD).
*   **Memoria RAM:** Por lo menos 8 GB de memoria. (Esto es importante porque el programa muestra gráficos en 3D del almacén).
*   **Sistema Operativo:** Windows 10 o Windows 11.
*   **Espacio Libre:** Al menos 10 GB de espacio libre en el disco duro.

### Requisitos Recomendados (Para máxima velocidad)
*   **Computador:** Procesador Intel Core i5 o AMD Ryzen 5.
*   **Memoria RAM:** 16 GB de memoria.
*   **Disco Duro:** Se recomienda fuertemente un Disco de Estado Sólido (SSD) para que el programa abra al instante y guarde la información de inmediato.

*Nota para el usuario: Si no estás seguro de qué componentes tiene tu computador, puedes pedirle al área de soporte de TI que confirme si tu máquina cumple con estos requisitos antes de iniciar la instalación.*
