# 4. INSTRUCCIONES DE INSTALACIÓN Y EJECUCIÓN

El sistema ha sido empaquetado para que su instalación en tu computador con Windows sea tan sencilla como instalar cualquier otro programa.

### 4.1. Instalación del Sistema
1.  **Obtener el Instalador:** Solicita al equipo de TI o a tu supervisor el archivo instalador llamado `Handler_TrackSamples_Setup.exe`.
2.  **Requisito Previo:** Asegúrate de que el programa **Docker Desktop** esté abierto y funcionando en tu computadora (verás el ícono de una pequeña ballena cerca del reloj en la esquina inferior derecha de tu pantalla). Si no lo tienes, pide soporte a TI.
3.  **Ejecutar:** Haz doble clic sobre `Handler_TrackSamples_Setup.exe`.
4.  **Asistente:** Sigue los pasos en pantalla (haciendo clic en "Siguiente" o "Instalar"). El programa configurará todo por ti, incluyendo la base de datos local donde se guardará toda la información.

### 4.2. Ejecución (Cómo Abrir el Programa)
Una vez finalizada la instalación, verás un acceso directo en tu escritorio llamado **"Handler TrackSamples"**. 
1.  Haz doble clic en ese ícono.
2.  Se abrirá la ventana principal de la aplicación mostrando la pantalla de "Iniciar Sesión".

### 4.3. Reinicio del Sistema
Si notas que el sistema se congela o se pone lento:
1.  Cierra la aplicación haciendo clic en la "X" roja en la esquina superior derecha de la ventana.
2.  Vuelve a hacer doble clic en el acceso directo del escritorio. Al hacer esto, el sistema y la base de datos se reconectarán automáticamente.

### 4.4. Desinstalación
Si por algún motivo necesitas borrar el programa de tu computadora:
1.  Asegúrate de tener el programa completamente cerrado.
2.  Ve al menú **Inicio de Windows**, busca "Agregar o quitar programas" y presiona la tecla Enter.
3.  Busca "Handler TrackSamples" en la lista de aplicaciones.
4.  Haz clic sobre él y selecciona **"Desinstalar"**. 
5.  El sistema eliminará automáticamente el programa y detendrá la base de datos interna. *(Nota: Asegúrate de haber realizado un backup antes de hacer esto si quieres conservar tus datos).*
