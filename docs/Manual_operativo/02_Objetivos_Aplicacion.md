# 2. OBJETIVOS DE LA APLICACIÓN

**Handler TrackSamples** es una herramienta informática creada para hacer tu trabajo diario más fácil, organizado y seguro. 

El sistema ha sido diseñado con los siguientes objetivos principales en mente:

1.  **Mantener el Orden del Almacén:** Brindarte un control exacto de qué materias primas entran, dónde están guardadas y cuándo salen de las instalaciones.
2.  **Garantizar la Seguridad Física:** Ayudarte a cumplir con las normas internacionales de seguridad química (SGA). El sistema es inteligente y te alertará si intentas almacenar dos productos químicos juntos que podrían reaccionar peligrosamente.
3.  **Evitar el Desperdicio (Sistema FEFO):** Cuando necesites despachar o utilizar una muestra, el programa te indicará automáticamente cuál frasco debes usar primero (el que esté más pronto a vencer), ayudando a la empresa a no desperdiciar material.
4.  **Trazabilidad Transparente:** Mantener un historial completo (un "libro de registro") donde queda anotado quién hizo cada tarea. Además, facilita la generación de etiquetas QR para que puedas identificar cualquier frasco usando un escáner.
5.  **Visualización Moderna:** Permitirte ver la bodega y los estantes desde tu pantalla a través de un mapa en 3D, para que sepas exactamente a qué pasillo ir sin perder tiempo buscando cajas.
